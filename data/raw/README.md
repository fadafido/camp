# Raw source data

One subfolder per institution (`khalifa`, `aus`, `unc`), holding the
catalogue-derived inputs for that university's programme. The contents are parsed
from the institution's **publicly published undergraduate course catalogue**:

- `extracted_courses.json` — courses with code, title, credits, level, subject
  and the verbatim prerequisite text parsed from the public catalogue.
- `extracted_program.json` — the programme's referenced courses and requirement
  structure parsed from the public catalogue.
- a cached catalogue artefact (e.g. the AUS catalogue PDF) where the source was a
  downloadable public document.

These feed `src/dataset/<inst>_ingest.py`, which normalise them into CAP-Bench
entities under `data/intermediate/<inst>/`. The `intermediate/` outputs are
gitignored and regenerated by the ingest scripts.

`khalifa/raw_catalog_local.json` is a second copy of the Khalifa SmartCatalogIQ
navigation sitemap (a local snapshot alongside `raw_catalog.json`); the scraper
reads `raw_catalog.json`, so the `_local` copy is retained only as a raw-source
backup and is not consumed by the pipeline.

CAP-Bench is a three-institution, mixed-field benchmark: Khalifa University
(Computer Science), American University of Sharjah (Information Systems), and UNC
Chapel Hill (Economics). All student data in the benchmark is synthetic; only the
course-catalogue structures are catalogue-derived.
